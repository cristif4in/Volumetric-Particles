Un mod ASI pentru GTA San Andreas pe care schimba particulele de la cauciucuri in joc cu unele volumetrice.

## Install

1. Un asi loader preinstalat.
2. Pune .asi-ul si .dll-ul langa gta_sa.exe
3. Incepe joaca.

**daca ai o problema sau un bug/eroare, te rog sa deschizi un issue aici pe acest repository.**
